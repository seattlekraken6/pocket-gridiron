# Pocket Gridiron

A 3D football game in the browser with real NFL rosters and jersey numbers (as of Nov 8, 2026).

- Call plays, throw with the mouse (hold for power, drag to place the ball)
- Take over ball carriers: juke, truck, slide
- Play defense: call a coverage, control a defender, dive, hit, swat
- Superstar traits, home/away/alternate uniforms, 17-game season with playoffs

Static site: just `index.html`. Deploys on Vercel with no build step (Framework Preset: Other).
